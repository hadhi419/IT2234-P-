Description:
This project focuses on mastering for loops, arrays, and an introduction to JSON in JavaScript. It includes various tasks involving iteration over numbers, array manipulation, and understanding the basics of JSON. The goal is to strengthen the understanding of data handling, iteration, and structured data representation in JavaScript.

Features:

Using for loops to print sequences of numbers.
Storing and manipulating numbers in arrays.
Finding the sum and average of an array.
Sorting an array in ascending and descending order.
Filtering even and odd numbers from an array.
Introduction to JSON: Understanding JSON structure, creating simple JSON objects, and accessing data from JSON.
