Description
This project was created to strengthen my JavaScript and Node.js skills by implementing core backend concepts such as handling HTTP requests with Express.js, working with arrays, and processing JSON data. The project includes practical applications of data retrieval, filtering, and searching functionalities.

Features:
1. Express.js and Node.js Server
Created a RESTful API using Express.js to manage student records.

Implemented multiple routes to handle HTTP requests.

Designed endpoints to fetch student details based on their registration number.

2. Array Manipulation and Searching
Stored student data as an array of objects.

Implemented filtering to retrieve students based on gender and course.

Used array methods like find() and filter() to search and retrieve student information dynamically.

3. JSON Data Handling
Managed student data in a structured JSON format.

Extracted student details based on unique registration numbers.

Processed and returned relevant data through API responses.

This project helped me solidify my understanding of backend development and improved my ability to work with APIs and JSON data in a real-world context.
