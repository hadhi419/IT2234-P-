Description
This project was developed to enhance my skills in JavaScript and Node.js by building a basic backend system that handles users and post comments using Express.js. The project demonstrates core backend principles such as RESTful API routing, modular code structure, JSON-based data processing, and array-based data manipulation.

Features:

Express.js and Node.js Server

Developed a RESTful API using Express.js to manage user and post (comment) data.

Structured the application using a modular approach with separate routers and service files.

Implemented routes to retrieve all users, fetch posts with associated comments, and more.

User and Comment Management

Stored data for users and posts in structured JavaScript arrays (simulating a simple database).

Connected user and post data using IDs to allow functionality like retrieving comments with user information.

Used array methods like find() and filter() to relate and retrieve relevant records dynamically.

JSON Data Handling

Processed user and post data in JSON format.

Implemented functionality to extract, combine, and return data such as a comment along with the commentator’s full name.

Responses are returned in a clean, structured JSON format for frontend or testing use.

Outcome
This assignment helped reinforce my backend development skills by implementing API endpoints, organizing application structure, and working with JSON data and arrays. It also gave me experience in connecting related data (users and comments) without relying on a database, which deepened my understanding of backend logic and routing in Express.js.
