Description:
This project was created to strengthen my JavaScript and Node.js skills by exploring key programming concepts such as loops, array manipulation, JSON handling, and backend development with Express.js. Through various tasks, I gained practical experience in data processing, iteration techniques, and working with web servers.

Features:
1. Node.js and Express.js Basics
Created an Express.js server to handle HTTP requests.

Implemented multiple routes to send different responses.

Built a basic Node.js server using the http module.

2. Array Manipulation and Iteration
Printed elements of an array using for loops and forEach.

Reversed arrays using push and pop.

Filtered common elements between two arrays.

Found the most frequent element in an array.

Calculated the maximum value in an array using forEach.

Worked with nested arrays using loops.

Implemented a two-sum problem to find pairs that add up to a target value.

3. JSON Data Handling
Created an array of student objects with properties like name, course, gender, and GPA.

Filtered students by gender to find female students.

Extracted students in the IT course using loops and filters.

Determined the maximum GPA among students.

Calculated the average GPA across all students.

This project helped me sharpen my problem-solving skills while applying JavaScript concepts in real-world scenarios.
